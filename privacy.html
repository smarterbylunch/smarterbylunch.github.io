Privacy Policy

Effective October 2, 2026

This policy covers two things run by Smarter by Lunch ("we"), an independent creator based in Windsor, Ontario:

  • This website, and
  • Smarter by Lunch Studio ("the Studio"), a private desktop application that runs on our own computer and that we use to make and manage videos for our YouTube and TikTok accounts.

The Studio is a single-owner tool. It is not offered to the public, and the only accounts that can connect to it are the Smarter by Lunch YouTube channel and TikTok account. It does not create user accounts or collect personal information from viewers or website visitors.

Two separate places. The website is hosted by GitHub (section 1). The Studio keeps its data only on our own computer (sections 2–7). No Studio data, sign-in tokens or videos are ever stored on the website or sent to GitHub.

1. This website (hosted on GitHub Pages)

This site is a set of static pages hosted by GitHub Pages, a service of GitHub, Inc. We do not run any code that collects information about you here: no cookies, local storage, analytics, advertising, forms or embedded third-party content. Fonts and images are served from this site.

GitHub's security logging: GitHub states that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes, whether or not the visitor is signed in to GitHub. Those logs are kept and controlled by GitHub, not by us, and we do not receive them. See About GitHub Pages: data collection and the GitHub General Privacy Statement.

2. Platform services the Studio uses

The Studio uses YouTube API Services (the YouTube Data API and YouTube Analytics API) and the TikTok Login Kit and Content Posting API. Your use of YouTube is governed by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. TikTok's handling of data is described in the TikTok Privacy Policy.

4. Service providers

  • Google / YouTube: video upload, status and statistics through YouTube API Services (Google Privacy Policy).
  • TikTok: sign-in and sending drafts through the Login Kit and Content Posting API (TikTok Privacy Policy).
  • Anthropic (Claude): an AI assistant used through our own subscription to research, write and plan lessons. It may receive lesson topics, scripts and, when we plan a video around viewer questions, short question text and summary statistics. It never receives sign-in tokens or credentials (Anthropic Privacy Policy).
  • GitHub: hosts this website (GitHub Privacy Statement).

Narration and video rendering run locally on our computer. The Studio also reads public web pages and news feeds for topic research. That reading involves no personal data.

5. Storage and security

All Studio data is kept on a local drive on our own computer. The Studio stores nothing on any viewer's or visitor's device. Sign-in tokens and credentials are encrypted (see section 3), and the Studio's own logs automatically redact secrets. The Studio talks to YouTube and TikTok only over their official, encrypted (HTTPS) APIs, and it does not automate their websites.

6. Retention and deletion

  • Sign-in tokens and cached account details are kept until we disconnect the account in the Studio, which deletes them immediately, or until they expire or access is revoked.
  • YouTube statistics and analytics are kept while we run the channel, and we confirm at least every 30 days that our authorization is still valid.
  • Other data from the YouTube API (for example our channel details and the status of an upload) is deleted or refreshed within 30 days.
  • YouTube viewer-question text is kept for no longer than 30 days.
  • Backups of the Studio's database and settings stay on our own drive. Only the most recent 14 are kept, and they never include sign-in tokens or credentials.
  • Temporary working files are deleted automatically after about 3 days.
  • Our own videos and written text are ours and are kept for as long as we run the channel.

When access is revoked. If we disconnect a platform in the Studio, or access is revoked in Google's or TikTok's settings, we delete the data obtained from that platform, including copies in our local backups, within 7 days. The sign-in tokens are deleted immediately on disconnect.

How deletion is done today: apart from tokens (deleted automatically on disconnect) and temporary files, these deletions are carried out by us by hand, following a written internal procedure: we remove the platform's statistics, upload records and viewer-question text from the Studio's database and from the backup copies, and record when it was done.

7. Revoking access

  • Google / YouTube: remove "Smarter by Lunch Studio" at Google security settings → third-party access.
  • TikTok: remove the app in the TikTok app's settings, under the apps and services your account has authorized.
  • In the Studio: Settings → Integrations → Disconnect deletes the stored tokens.

8. Children

Our content is made for adults at work. Neither this site nor the Studio is directed to children, and neither knowingly collects information from them.

9. Changes

If our data handling changes, we will update this page and its effective date.
