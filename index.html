About our desktop studio tool

Smarter by Lunch Studio is a private desktop application that runs on the Smarter by Lunch owner's own computer. It helps one person research, script, voice and render the channel's videos. It is not offered to the public, and nobody else can sign in to it.

  • It connects only to the Smarter by Lunch YouTube and TikTok accounts, through the official YouTube Data API, YouTube Analytics API and TikTok Login Kit / Content Posting API.
  • Every video is reviewed by the owner before anything goes to a platform. On YouTube, uploads are private. On TikTok, videos go to the account's drafts inbox, where the owner finishes and posts them in the TikTok app.
  • It reads the channel's own performance statistics so the owner can see what is useful to viewers.
  • Sign-in keys stay on the owner's computer, encrypted, and are never shared.
